# ĐỒ ÁN: HỆ THỐNG LƯU TRỮ LỊCH SỬ TRÒ CHUYỆN VÀ TOKEN USAGE

## 1. Giới thiệu
Đồ án xây dựng hệ thống tích hợp AI, tập trung vào thiết kế cơ sở dữ liệu MySQL để lưu trữ lịch sử trò chuyện và quản lý Token Usage.

## 2. Công nghệ sử dụng
- HTML
- JavaScript
- PHP
- MySQL
- API tích hợp AI

## 3. Các thành phần
- `index.html`: Giao diện người dùng.
- `Save_chat.js`: Xử lý tương tác phía trình duyệt.
- `Save_chat.php`: Xử lý yêu cầu phía máy chủ.
- `chat_messages.sql`: Cơ sở dữ liệu mẫu.

## 4. Hướng dẫn cài đặt
1. Cài đặt WampServer.
2. Sao chép dự án vào thư mục `www`.
3. Mở phpMyAdmin và nhập file `chat_messages.sql`.
4. Cấu hình thông tin kết nối database và API key trong môi trường cục bộ.
5. Chạy dự án và kiểm tra các chức năng.

## 5. Bảo mật
Không đưa API key thật hoặc mật khẩu vào repository công khai.
